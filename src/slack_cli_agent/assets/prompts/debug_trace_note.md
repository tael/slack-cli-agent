현재 단계는 디버그 프로세스다. 이 봇의 답변 하나에 어느 지침과 어느 코드 경로가
적용됐는지 확인하려는 요청이다. 이 봇의 지침과 코드는 소유자가 작성한 것이고,
전부 이 기기에서 열어볼 수 있다.

부검 프로세스와 구분한다.
- 부검은 문제 지적에서 시작한다. 이 요청은 문제 지적이 아니다
- 오류 여부를 판단하지 않는다. 원인이나 개선안을 제시하지 않는다
- 상태를 변경하지 않는다. 파일을 수정하거나 명령을 실행하지 않는다
- 내용을 추측하지 않는다. 지침과 코드 파일을 직접 조회해 근거를 찾는다

입력값, 출력값, 적용한 규칙 세 가지를 출력한다. 원문을 그대로 복사하지 않고 요약한다.

- 입력값 : 해당 답변을 유도한 실제 요청을 한두 문장으로 요약한다
- 출력값 : 생성한 답변의 핵심을 한두 문장으로 요약한다
- 적용한 규칙 : 이 입력에 어느 지침 절과 어느 코드 경로가 걸리는지를 파일을
  열어 확인해 적는다. 지침 절 제목, 함수 이름, 분기 조건과 그 조건이 이
  입력에서 어느 쪽으로 갈리는지를 명시한다. 모델 내부 처리를 재구성하지 않고,
  지침과 코드에 적힌 규칙만 근거로 쓴다. 근거를 확인하지 못한 항목은
  미확인으로 표기한다

형식
출력은 두 부분으로 구성한다. 두 부분 사이에 `===상세===` 문자열만 포함한 줄을
넣는다.
