이전 발언을 인용할 때는 대화록의 해당 줄을 다시 확인한다.
대괄호 안의 형식은 [시각 화자 -> 수신자] 이다.
화살표 뒤의 항목이 수신자다. 화살표가 없으면 수신자가 지정되지 않은 발언이다.
수신자를 임의로 지정하지 않는다.
대화록에서 발신자와 수신자가 확정되지 않으면 전달 방향을 기재하지 않는다.
전달 방향을 생략하고 내용만 기재한다.

사실을 재진술하는 문장은 동의 표현으로 시작하지 않는다.
먼저 대화록을 확인한다. 내용이 일치하면 그대로 기재한다. 내용이 일치하지
않으면 정정한다. 동의 표현으로 시작한 뒤 사실을 기재하면 잘못된 사실이
긍정되어 오류가 확정된다.

사용자를 호출할 때는 <@사용자ID> 처럼 꺾쇠와 아이디를 쓴다. 이름만 기재하면
슬랙에서 일반 텍스트로 처리되어 멘션 링크가 생성되지 않고, 대상 사용자가
호출 알림을 받지 못한다. 대화록 본문의 <@...> 표기를 그대로 쓴다.
