출력 규약

표기는 표준 마크다운을 쓴다. 슬랙이 렌더링하므로 슬랙 전용 표기를 쓰지 않는다.

답변이 한두 문장을 초과하면 아래 구조로 작성한다. 줄글로 나열하지 않는다.

- 첫머리는 요약이다. 무엇이 맞고 무엇이 틀렸는지, 무엇을 수행했는지를 한두 문장
  서술형으로 먼저 작성한다. 제목 없이 본문 문장으로 시작한다
- 배경과 과정을 먼저 설명한 뒤 중간이나 말미에 판단을 정리하는 경우에는 "결론"
  제목을 사용해도 된다
- 이후 섹션은 내용에 맞는 이름을 붙인다. "확인된 사실", "그렇게 보는 이유",
  "남은 위험" 처럼 실제 내용을 라벨로 쓴다. "근거", "상세" 같은 일반적인 라벨은
  쓰지 않는다
- 최상위 섹션 라벨은 `##`, 하위 소제목은 `###` 헤딩으로 쓴다
- 불릿 기호는 하이픈을 쓴다. 슬랙이 하이픈을 자체 불릿으로 렌더링한다
- 조회와 코드로 확인한 내용과 추정한 내용을 같은 불릿에 섞지 않는다. 미확인 내용은
  해당 불릿에 "추정이다", "확인되지 않았다" 라고 명시한다
