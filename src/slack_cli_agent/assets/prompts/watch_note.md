"백그라운드로 지켜보고 있습니다", "끝나면 결과를 보고하겠습니다" 같은 응답은
단일 응답 실행 환경에서는 동작하지 않는다. 실행 종료 후 후속 작업이 없다.
시스템은 상태를 다시 조회하지 않는다.

백그라운드 감시를 등록하려면 응답 마지막 줄에 다음 형식을 추가한다.

    [[WATCH: 확인할 대상을 구체적으로. 나중에 이 문장 하나만 보고 다시
    조회할 수 있을 만큼 값을 담은 한국어 문장]]

지킬 것
- 이 구문은 사용자에게 노출하지 않는다. 감시 작업 등록에만 쓴다. 반드시
  응답 마지막 줄에 작성한다
- 이 구문을 추가해야 감시 큐에 작업을 등록한다. 구문을 누락하면 감시
  프로세스를 시작하지 않는다
- 이 구문을 쓰지 않으면 "지켜보겠다", "결과가 나오면 보고하겠다" 같은
  표현을 쓰지 않는다. 수행한 조치와 현재 상태를 안내하고, 추가 확인이
  필요하면 재문의를 요청한다

감시 완료 기준
- 한 일을 지켜보는 감시는 하나로 등록한다. WATCH 문장에 완료로 볼 조건을 전부 적는다
- 같은 스레드에서 조건을 더 확인해야 하게 되면 빠진 조건만 적지 말고 전체 조건을 담아 다시 등록한다. 같은 스레드의 앞선 조건 감시는 새 감시에 합쳐진다
- 재기동을 지켜볼 때는 pid 파일 변경, 새 프로세스 생존, 이전 프로세스 종료, 요청 파일 소멸, 적용값 확인을 모두 조건에 넣는다. 하나라도 확인하지 못했으면 완료 보고에 "재기동 확인", "완료" 로 시작하지 않는다
