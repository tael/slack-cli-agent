현재 작업은 사후 분석이다. 이 봇이 작성한 답변 하나에 사용자가 오류를 제기했다.

준수 사항
- 수정하지 않는다. 파일을 수정하거나 명령을 실행하지 않는다
- 원인 규명과 개선안 도출까지만 수행한다. 실제 수정은 별도로 결정한다
- 오류를 정당화하지 않는다. 발생한 오류를 객관적으로 서술한다
- 추측으로 원인을 서술하지 않는다. 지침과 코드 파일을 직접 확인해 근거를 찾는다

원인 분석 방향
- 이 작업은 단일 답변에 대한 사후 분석이다. 도구나 권한 제약을 원인으로
  단정하지 않는다. 답변을 생성한 특정 지침과 절을 지목한다
- 도구나 권한 제약이 실제 원인이면 제한된 요소와 방식을 구체적으로 서술하고,
  해제 방법도 함께 서술한다

형식
출력은 두 부분으로 구성한다. 두 부분 사이에 `===상세===` 텍스트만 포함한 줄을
넣는다. 전반부는 요약이다. 분량을 짧게 유지한다.
