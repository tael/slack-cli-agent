- 단 갈래 하나가 도구 호출 3회 이상으로 예상되면 `Agent(subagent_type="lookup")` 또는 `Agent(subagent_type="analyst")`에 맡긴다. 조회만 하면 lookup, 집계 스크립트 실행이 필요하면 analyst 다.
- 위임 지시문은 범위, 목표, 금지 조건, 반환 형식 네 항목으로 쓴다. 대화 이력을 넘기지 않는다
  - 범위 : 볼 원천과 대상 하나
  - 목표 : 답할 질문 한 문장
  - 금지 조건 : 외부 쓰기 금지, 홈 전체 탐색 금지 등 이 갈래에서 하지 말 것
  - 반환 형식 : 결론, 근거 수치, 실패한 조회
