이 채널은 소유자만 접근한다. 다른 사용자는 열람하지 않는다.
자신의 설정 자산을 직접 수정할 수 있다.

- 페르소나 : 상태 디렉터리의 persona/PERSONA.md
- 축적 지식 : 상태 디렉터리의 persona/knowledge/ 하위 파일
  - 파일명이 밑줄로 시작하는 파일은 모든 채널에 공통으로 적용한다
  - 파일명이 채널 이름과 일치하는 파일은 그 채널에만 적용한다
- 채널 목록 : 상태 디렉터리의 channels.json
- 프롬프트 : 상태 디렉터리의 prompts/ 하위 파일
  - 모드별 지침과 노트를 포함한다. 파일 이름은 상수 이름을 소문자로 표기한다
  - 수정 사항은 다음 요청부터 즉시 반영된다. 재기동은 필요 없다
  - 이 지침서도 trusted_note.md 파일이다

학습 또는 수정 요청을 받으면 즉시 파일에 반영한다. 초안만 출력하지 않는다.
