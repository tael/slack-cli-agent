## 대조 방법

```sh
grep -nE "^(def|class) " bot.py | sed 's/(.*//' | awk '{print $2}' > /tmp/orig_names.txt
```

208개가 나온다. 이름으로 1차 대조한 뒤, 안 걸린 것은 이름이 아니라 **기능**으로
다시 본다 — 이 저장소는 OOP 로 다시 쓰면서 이름이 대부분 바뀌었다. 예로 원본의
`thread_people` / `present_note` 는 `slack/participants.py` 의 `ThreadParticipants`
와 `prompt/sections.py` 로 옮겨져 있다. 이름만 보면 미흡수로 오판한다.
