### 2026-09-24 교정 — `is_allowed` 와 자동 등록

위 두 행은 흡수로 적혀 있었으나 실제로는 둘 다 없었다(sca-a8pp · sca-bu54).
`is_allowed` 자리에 적힌 것은 관리 명령의 신뢰 등급 판정이라 다른 기능이고,
`ChannelRegistry.update()` 를 부르는 곳은 관리 명령 네 곳뿐이라 소유자 호출로
등록되는 경로가 없었다. 그래서 봇이 들어간 채널의 누구나, 소유자가 아닌 DM
발신자가 엔진 턴을 돌릴 수 있었다.

되살리면서 원본과 다르게 한 것은 셋이다.

- **자동 등록의 `mode` 가 `private` 이 아니라 `default`** 다. 이 저장소는 미등록
  채널을 `default` 로 답하고 있어, `private` 으로 적으면 지금 도는 채널의 응답
  형식이 등록과 동시에 바뀐다
- **에이전트 패널(`assistant_thread_started`) 에도 같은 판정을 건다.** 원본에 없는
  경로다. 패널이 여는 것은 DM 이라 원본의 DM 규칙을 따랐다 — 인사를 올리면 뒤이어
  보내는 말은 전부 무시되는데 봇이 있다는 것만 알리게 된다
- **리액션 경로에는 걸지 않는다.** 원본 `on_reaction`(bot.py:6143) 에도 없다.
  이 봇이 자기 답변을 올린 자리에만 붙는 것이라 이미 응답한 대화다

캐치업에는 두 번째 판정 자리를 두지 않았다. 캐치업이 훑는 대상은 등록된 채널
목록(`Application.channel_ids()`) 뿐이라 거기서 나온 요청은 누가 보냈든 판정을
통과한다.

### 이 대조가 입증하지 않는 것

**각 행은 대응물의 위치와, 원본과 다른 점까지만 적었다.** 그것이 정상 경로·
예외 경로·재시도 경로·종료 경로 전부에서 실제로 지나는지는 아직 행마다 적지
않았다 — [[feedback_module_built_is_not_module_wired]] 의 자리다. 클로드·코덱스·
제미나이 세 엔진이 같은 로직으로 지나는지는 엔진별 능력 차이(`reports_output_tokens`
· `reports_cache_usage` · `splits_tool_time`)를 따로 다룬다.

**다음 판에서 행마다 채울 것** — 정상 진입 경로, 예외·재시도·종료 경로, 접수기와
워커 사이의 상태 전달 방식, 다중 워커에서의 동작, 검증한 시험 또는 재현 절차,
그리고 등가·의도적 변경·미검증·미흡수 중 어느 판정인지.

## 다시 대조할 때

이 표를 갱신한다. 새로 만든 이슈는 표의 "미흡수" 절에서 지우고 "흡수된 것" 으로
옮긴다. 원본이 갱신되면 대조 명령을 다시 돌린다.

**"나머지는 전부 헬퍼" 로 끝내지 않는다.** 표본 검사는 "전부 흡수" 의 증명이
못 된다. 미매치를 전부 훑되, 이름이 아니라 **원본의 docstring 을 읽어** 판정한다.
외부에서 관찰되는 것부터 본다 — 권한·프롬프트·엔진 전환·이벤트 진입·영속화·
재시작 복구·슬랙 호출·사용자 출력·상태 변경. 순수 문자열 변환과 조회 보조가
뒤다.

    cd /Users/taelkim/Projects/mametchi-slack-bot
    grep -nE "^(def|class) " bot.py | sed 's/(.*//' | awk '{print $2}' \
      | sed 's/:$//' | sort -u > /tmp/orig.txt
    cd /Users/taelkim/Jobs/slack-cli-agent
    python3 -c "
    import pathlib
    orig = [l.strip() for l in open('/tmp/orig.txt') if l.strip()]
    blob = '\n'.join(p.read_text(errors='ignore') for p in pathlib.Path('src').rglob('*.py'))
    print('\n'.join(n for n in orig if n not in blob))"

이름 하나씩 `grep -r` 로 도는 방식은 208회 실행이라 2분을 넘긴다. 위처럼
한 번 읽어 메모리에서 대조한다.

**기능으로 2차 대조할 때는 이름이 아니라 그 일을 뭐라고 부르는지로 찾는다.**
이 저장소는 이름을 거의 다 바꿨으므로, 원본 docstring 의 서술어를 검색어로
쓴다(예로 "다른 봇", "화자", "남겨둔 보고").

**그 검색이 못 잡는 자리가 둘이다.**

    조직 고유값을 뺀 기능    원본 낱말이 여기엔 아예 없다
    이름이 주석·문자열에만   매치가 나와도 구현이 아니다
