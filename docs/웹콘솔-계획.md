# 웹 콘솔 계획

사용자 지시(2026-09-15) — 설정 값을 읽고 고칠 수 있는 화면을 만든다. 원본
`mametchi-slack-bot/dashboard/` 의 지표 화면과 한 화면으로 같이 설계한다.
구현은 표준 라이브러리만 쓴다.

## 원본에서 가져오는 결정

원본 설계서(`dashboard/README.md`)에 근거가 적힌 것들이다. 다시 판단하지 않는다.

- **외부 의존성을 쓰지 않는다.** 사내망·오프라인에서도 열려야 한다. 차트는 CSS
  막대와 인라인 SVG 로 그린다
- **`127.0.0.1` 에만 묶는다.** 질문·답변 원문과 토큰·비용이 화면에 나온다
- **봇 상태는 스냅샷 파일로 읽는다.** 봇 프로세스에 HTTP 를 넣지 않는다 — 그러면
  봇이 죽었을 때 화면도 안 뜬다
- **스냅샷이 20초 넘게 안 바뀌면 "상태 모름" 이다.** 마지막 값을 현재로 읽지 않는다
- **서버 하나가 프로필 전부를 본다.** 봇마다 서버를 띄우지 않는다
- **HTTP/1.1 로 응답한다.** HTTP/1.0 은 응답마다 연결을 닫아 TIME_WAIT 가 쌓인다.
  원본은 5초 폴링 나흘에 5,621개가 남아 새 연결이 막혔다
- **감사 기록 파싱 결과를 잠깐 담아 둔다.** 같은 초에 여러 탭이 새로고침해도 다시
  훑지 않는다

## 구조

    src/slack_cli_agent/web/
        server.py        http.server 기반. 라우팅과 바인딩
        api.py           경로 -> 핸들러. JSON 을 낸다
        editor.py        프로필·채널 읽기와 쓰기. 검증 포함
        files.py         프롬프트·지식 파일 읽기와 쓰기
        metrics.py       지표 수집. 신규 저장소(SQLite + StatePaths) 기준
        assets/index.html

`assets/` 는 패키지 동봉 자료다. `pyproject.toml` 에 package data 로 넣는다 —
설치물이 자기 화면을 들고 있어야 설치 직후에 열린다.

진입점은 `slack-cli-agent web [--profile-dir DIR] [--port 8787] [--open]` 이다.
다른 명령과 달리 `--profile` 을 요구하지 않는다. 화면에서 봇을 고른다.

## 모듈 계약

병렬로 만들기 위해 시그니처를 먼저 고정한다.

    class ProfileEditor:
        def __init__(self, search_dirs: Sequence[Path]) -> None
        def names(self) -> list[str]
        def read(self, name: str) -> dict[str, object]
        def save(self, name: str, data: Mapping[str, object]) -> list[str]
            # 돌려주는 것은 검증 오류 목록이다. 비어 있으면 저장에 성공한 것이다.
            # 저장은 임시 파일을 거쳐 os.replace 로 교체한다.

    class ChannelEditor:
        def __init__(self, registry: ChannelRegistry) -> None
        def list(self) -> list[dict[str, object]]
        def update(self, channel_id: str, changes: Mapping[str, object]) -> dict[str, object]

    class FileEditor:
        def __init__(self, root: Path, *, suffix: str = ".md") -> None
        def names(self) -> list[str]
        def read(self, name: str) -> str
        def write(self, name: str, text: str) -> None
            # root 밖을 가리키는 이름은 거부한다.

    class MetricsCollector:
        def __init__(self, profile: Profile) -> None
        def collect(self, days: int) -> dict[str, object]

`MetricsCollector.collect` 가 내는 키는 원본 `metrics.collect` 와 같게 둔다 —
화면을 원본 것에서 옮겨 쓰기 위해서다.

    generated_at window_days bot bots snapshot last_answer_kst channels
    responsiveness reliability quality usage followup tools queue_wait
    usage_block session_total

## 원본과 달라지는 것

- **지표의 원본 데이터가 다르다.** 원본은 `audit.jsonl`·`sessions.db`·
  `postmortems.json` 을 따로 읽었지만 신규는 `state.db` 한 곳에 있다.
  `metrics.py` 는 옮겨 쓰는 것이 아니라 다시 쓴다
- **쓰기가 생긴다.** 원본은 읽기 전용이었다. 프로필 저장은 검증을 통과해야 하고
  임시 파일을 거쳐 교체한다. 채널 설정은 기존 `ChannelRegistry.update` 를 쓴다
- **프롬프트·지식 편집이 생긴다.** 경로 탈출을 거부하는 판정이 필요하다
