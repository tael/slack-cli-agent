## 순서

1. **d 쿠키 추출** — 키체인의 Slack Safe Storage 로 쿠키 DB 를 푼다. 런북은
   `~/.claude/slack-relay/docs/slack-app-infra.md`
2. **앱 생성** — config token 발급 모달에는 tael 이 안 나온다. UI 의
   `?new_app=1` 흐름을 쓴다. `[role=radio]` 중 "From a manifest" 를 누르고
   Continue, 워크스페이스에서 tael 을 고르고, 매니페스트는 CodeMirror 에
   키보드 입력으로 넣는다(`setValue` 로는 Next 가 안 켜진다)
3. **앱 한도** — tael 은 설치 앱 10개가 상한이다. 넘으면 Next 가 비활성인 채로
   "app limit" 경고가 뜬다. 하나를 내려야 한다. 내리는 위치는
   `https://tael.slack.com/apps/<APP>` 의 구성 탭 → 앱 제거
4. **설치** — `/install-on-team` 에서 "Install to tael" → 허용. 토큰은 `/oauth`
   페이지에서 읽는다
5. **소켓 토큰** — Basic Information → Generate Token and Scopes →
   connections:write. 스코프 목록은 모달 밖에 렌더되므로 좌표로 누른다
6. **상태 디렉터리** — `slack-cli-agent init --name <봇> --state-dir <경로>`
7. **엔진 격리** — 프로필의 `primary_engine.home_dir` 이 CODEX_HOME 이 된다.
   **새 홈에는 로그인 정보가 없다.** `~/.codex/auth.json` 을 600 으로 복사한다
8. **기동** — 상태 디렉터리에 venv 를 만들고 `pip install -e` 한 뒤
   `worker` 와 `ingress` 를 각각 띄운다

## 이름을 바꿀 때 (2026-09-15 구치파치 → 아스카)

    앱 이름        Basic Information 의 input[name=name]. 저장 즉시 반영
    봇 표시명      App Home → App Display Name → Edit. #display_name 은 한글 가능
    봇 기본명      같은 모달의 #username. ASCII 만
    아이콘        /general 의 #app_icon 에 넣으면 자동 저장된다. Save Changes 는 안 눌러도 된다
    성격          상태 디렉터리의 persona/PERSONA.md. 여기에 이름을 적어야 봇이 자기 이름을 안다

**입력은 키보드로 한다.** `fill()` 이나 `setValue()` 로 넣으면 저장 버튼이 안 켜진다.
페이지가 keyup 을 듣기 때문이다. 아이콘의 `setInputFiles` 도 Basic Information
쪽에서는 저장이 안 켜지고 `/general` 쪽에서만 자동 저장된다.

**재설치는 스코프가 바뀔 때만 필요하다.** 앱 이름과 봇 표시명은 저장 즉시
`bots.info` 와 `users.info` 의 `real_name` 에 반영된다. 이것을 `users.info` 의
`name` 으로 확인하면 안 바뀐 것으로 잘못 읽는다.

**`users.info` 의 `name` 은 안 바뀐다.** 봇 사용자 생성 시점에 고정되는 옛 핸들이고
재설치로도 그대로다. 화면에 보이는 이름은 전부 `real_name` 과 표시명을 쓰므로
동작에는 영향이 없다. 이 값까지 맞추려면 앱을 새로 만들어야 한다.
